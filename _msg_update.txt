docs: 新增《如何更新》指南（实测 v0.2.0→v0.2.1 更新流程）

## 新增
- docs/guide/如何更新.md：三种更新方式（下载新 zip / 原地更新 / git pull）
  * 方式 A（推荐）：下载新 zip → 解压到新目录 → install.bat → 删旧目录
  * 含**实测验证结果**（v0.2.0 → v0.2.1 全流程）
  * 明确两个注意点：
    - 旧目录仍是旧代码（run.py 加载自己的 src/），建议删除
    - 不要覆盖解压到同一目录，用新目录更干净
  * 更新不会丢数据（不碰 LX 本体与 LxDatas）

## 实测结论（关键）
已装 v0.2.0 后装 v0.2.1：
  离线装依赖 OK → pip install -e . 自动覆盖 OK
  新目录版本 0.2.1
  全局 lx     0.2.1（status-install: mode=editable, 指向新目录）
=> 全局 lx 自动重定向到新目录，**无需先卸载**
