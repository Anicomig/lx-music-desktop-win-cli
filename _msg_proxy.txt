## 更正原排障文档的错误归因

原《安装排障清单》§2.2 称 502 是"未绕过系统代理"所致。
真机实测证明**归因不准确**：

    proxy_bypass('127.0.0.1') = True   -> requests 自动豁免本机
                                          即便强制指定 proxies 也返回 200
    proxy_bypass('0.0.0.0')   = False  -> 0.0.0.0 不豁免，会被发给系统代理
    http://0.0.0.0:23330/status  -> 502   ★
    http://127.0.0.1:23330/status -> 200

真凶链条：
    bindLan=true -> host=0.0.0.0
      -> requests 认为 0.0.0.0 非本地，发给系统代理
      -> 代理连不上 0.0.0.0（监听通配符，非可连接目标）
      -> 502

## 两处修复重新定性

* host 固定 127.0.0.1：**主修复**（真凶）★★★
* _local_session(trust_env=False)：**防御性加固**，保留
  （企业 PAC 可能连 127.0.0.1 也代理；成本为零，收益明确）

分工约定不变：本机端点绕代理，外网搜索走代理。
